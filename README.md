# HostelConnect

HostelConnect is a full-stack Hostel Complaint & Resolution System developed for colleges to streamline complaint registration, tracking, and resolution between students and hostel wardens.

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend (In Progress)
- Spring Boot
- Spring Security
- JWT Authentication
- PostgreSQL
- JPA/Hibernate

## Features

### Student
- Dashboard
- Submit Complaint
- View My Complaints
- Complaint Upvoting
- Notices
- Notifications
- Profile Management

### Warden
- Dashboard
- Manage Complaints
- View Complaint Details
- Update Complaint Status
- Publish Notices
- Profile Management
